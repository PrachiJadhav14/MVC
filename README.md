# 🚀 ASP.NET MVC Project

## 📌 Overview
This project is developed using ASP.NET MVC, C#, Entity Framework, and SQL Server. It demonstrates CRUD operations, database connectivity, and clean application structure following MVC architecture.

## 🛠️ Technologies Used
- ASP.NET MVC
- C#
- Entity Framework
- SQL Server
- HTML
- CSS
- Bootstrap

## ✨ Features
- Create Records
- View Records
- Update Records
- Delete Records
- Search Functionality
- Database Integration

## 🎯 Concepts Covered
- MVC Architecture
- CRUD Operations
- Entity Framework
- Repository Pattern
- SQL Server Connectivity
